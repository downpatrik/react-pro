# Итоговый проект React PRO — DogFood

Доработан магазин из [стартового репозитория NelliEfr](https://github.com/NelliEfr/REACT_PRO_final_project_base/). Исходники импортированы в папку `final-project` отдельным коммитом.

## Запуск

Команды выполняются из корня репозитория. Нужен Node.js 20.19+ в ветке 20.x или Node.js 22.12+.

```sh
npm --prefix final-project ci
npm --prefix final-project start
```

Откройте `http://localhost:8080`. Для каталога, избранного, отзывов и профиля нужен учебный аккаунт. API по умолчанию — `https://api.v2.react-learning.ru`. Его адрес можно задать переменной `API_URL` при сборке. [Документация API](https://api.v2.react-learning.ru/api).

Токен хранится в `localStorage` под ключом `dogfood.authToken`. После перезагрузки приложение восстанавливает профиль через `/users/me`. При выходе токен удаляется.

```sh
npm --prefix final-project run lint
npm --prefix final-project run typecheck
npm --prefix final-project run build
npm --prefix final-project run preview
```

Vite собирает приложение в `final-project/dist`. Для production-размещения настройте отдачу `index.html` для маршрутов React Router.

## Что сделано

1. **Архитектура.** Формы авторизации, корзина, поиск и каталог размещены в `features`. Страницы компонуют фичи. Список каталога и корзина читают свои данные через RTK Query и селекторы. Общие `Button`, `Input`, `Spinner` и `Modal` не обращаются к стору или API.
2. **Рендеры.** Карточка каталога подписывается на наличие конкретного товара в корзине. `memo` у карточек каталога и корзины помогает пропускать рендер при неизменных props. Изменение количества сохраняет ссылки на остальные позиции. `useMemo` кеширует фильтрацию избранного и расчёт суммы корзины, `useCallback` стабилизирует обработчики добавления и подгрузки.
3. **Portal и фокус.** Удаление из корзины подтверждается в модалке через `createPortal` в `#modal-root`. Нативный `dialog` изолирует фон. Крестик получает начальный фокус. Escape, фон и отмена закрывают окно и возвращают фокус на кнопку удаления.
4. **useRef.** Модалка хранит начало жеста по фону в ref без рендера. Форма входа использует ref для автофокуса email. Infinite scroll наблюдает за элементом через DOM-ref.
5. **Сборки.** Приложение запускается и собирается через Vite с плагином React SWC. Сборка обрабатывает TypeScript, CSS Modules и SVG-компоненты. Адрес учебного API передаётся через `API_URL`.
6. **React 19.** `useOptimistic` меняет состояние сердца до ответа API. Успех обновляет кеш списка и карточки, ошибка возвращает исходное состояние и показывает уведомление. `useActionState` управляет отправкой отзывов, очисткой после успеха и сохранением черновика при ошибке.
7. **Сценарии магазина.** Поиск сохраняет параметр `q` в URL. Профиль загружает и сохраняет данные через `/users/me`. В карточке товара можно поставить оценку от 1 до 5 и написать отзыв. Форма отправляет `text` и `rating` через `POST /reviews/leave/{productId}` с токеном авторизации. После ответа API отзыв и средняя оценка обновляются сразу в карточке. Корзина хранится в Redux, исходный обработчик оформления заказа выводит состав заказа в консоль. [Документация метода](https://api.v2.react-learning.ru/api#/Reviews/ReviewController_leaveReview).

## Структура

```text
src/
  app/                Каркас приложения и общие стили
  pages/              Маршруты каталога, корзины, профиля и форм
  features/
    auth/             Вход, регистрация и запросы профиля
    cart/             Список корзины, счётчики и Redux-слайс
    products/         Каталог, избранное, товары, отзывы и RTK Query
    search/           Поиск с debounce и сортировка
  shared/ui/          Общие презентационные компоненты
  shared/store/       Настройка Redux, общие хуки и базовый запрос
  widgets/            Шапка и подвал
```

## Профилирование

React DevTools Profiler 8.0.0, Chrome. В каталоге из шести карточек добавили один товар в пустую корзину. В контрольном прогоне карточка подписывалась на весь массив корзины. После изменения она получает из Redux только логическое значение для своего товара.

| Подписка карточки        | Карточек в каталоге | Рендеров `Card` |
| ------------------------ | ------------------: | --------------: |
| На всю корзину           |                   6 |               6 |
| На наличие своего товара |                   6 |               1 |
