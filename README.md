# React PRO

Учебное приложение на React, TypeScript.

## Запуск

```bash
npm ci
npm run dev # http://localhost:5173/tasks
npm run build
npm run lint
```

## Страницы

- `/tasks` - управление задачами.
- `/register` - регистрация на RHF с Zod и динамическими ссылками.
- `/subscribe` - двухшаговая подписка на `useActionState`.

Формы используют учебную асинхронную отправку без backend.
